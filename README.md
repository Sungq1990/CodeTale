# CodeTale

**CodeTale** — A lightweight novel reading plugin for IntelliJ IDEA.  
Enjoy your favorite books and novels directly within your IDE, without leaving the development environment.  

**CodeTale** — 一款轻量级 IntelliJ IDEA 小说阅读插件，让你在编码间隙轻松阅读喜爱的书籍和小说，无需离开开发环境。

## Features / 功能
- Chapter-based reading / 章节阅读  
- Jump to specific page / 页码跳转  
- Auto page turning / 自动翻页  
- View content in IntelliJ IDEA status bar / 在状态栏查看内容  
- Navigate chapters in the CodeTale tool window / 在 CodeTale 侧边栏选择章节  
- Reading progress with boss key / 阅读进度与老板键一键隐藏

## Usage / 使用说明
1. **Configure the plugin**  
   Go to **IDEA Settings > Tools > CodeTale** to set the novel file path and auto page turning interval.  
   在 **IDEA 设置 > 工具 > CodeTale** 中配置小说路径和自动翻页秒数。

2. **Read in the status bar**  
   The current chapter content will appear in the **IDEA bottom-left status bar**.  
   小说内容会显示在 **IDEA 左下角状态栏**。

3. **Navigate chapters**  
   Open the **CodeTale** tool window to select chapters. Double-click a chapter to display its content.  
   在 **CodeTale** 侧边栏选择章节，双击即可显示内容。

> If the navigation bar is shown in the bottom left corner instead, click **IDEA Top Menu > View > Appearance > Navigation Bar > Top** to move it to the top, then double-click the chapter again.  
> 如果左下角展示的是导航栏，需要依次点击 **IDEA 顶部菜单栏 > View > Appearance > Navigation Bar > Top**，将导航栏移到顶部，再次双击章节即可展示。
